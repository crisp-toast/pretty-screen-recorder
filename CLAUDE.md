# Working on Pretty Studio (the code)

- **Using** the tool to make videos: read `docs/AGENT_GUIDE.md` (`pretty guide`). This file covers **changing** the tool.
- The repo lives on Master Storage, and the path has a space, so quote it. Build with `scripts/build.sh` (release CLI + `dist/Pretty Studio.app`, signed ad-hoc). Debug iteration: `swift build --product pretty` and `.build/debug/pretty`.
- Run one heavy job at a time on this 16 GB Mac. A Swift build counts as one, and so does a render or a recording.
- The CLI and the app share `PrettyCore`. `Composer` is the only renderer, used by export, stills, sheets and the editor preview.
- Adding a project key means updating, in this order:
  1. The struct in `Model/Project.swift`, including its `CodingKeys` and its `init(from:)` defaults.
  2. `Bundle/Schema.swift`, which drives the docs and unknown-key warnings.
  3. The renderer.
  4. Optionally, an inspector control in `Sources/PrettyStudio/Inspector.swift`.
- Directing lives in `PrettyCore/Direct/Director.swift` (plan, scenes, copy lint, apply, conform). Audio lives in `PrettyCore/Audio/`: `Narrator` (ElevenLabs/OpenAI, cached by content), `Voice` (word-timing utilities only — there is deliberately no on-device TTS), `MusicLibrary` (incompetech CC BY catalog, licensed folder, credits), `MusicGen` (offline synth fallback), `BeatGrid`/`BeatDetect`, and `AudioPlan` (mode resolution plus captions). Kinetic type is `Render/Kinetic.swift`. Setup/secrets/brand extraction are in `PrettyCore/Setup/` (`Secrets` = login Keychain via `security -i`, `-A` ACL). The app's onboarding/Settings are in `Sources/PrettyStudio/Setup/`.
- Treatments (`Direct/Treatment.swift`) drive look/motion/sound; `Director.plan` picks one (history in `<project>/marketing/.pretty-history.json`), composes the score in two passes (`Audio/Score.swift`), plans moves/shots/SFX. Stages are `Backgrounds.stage`. Device moves and light sweep are in `Composer.deviceState`; 3D shots are `Render/Shots.swift` + `scripts/blender/device_shot.py` (Blender headless, frames cached under `<bundle>/shots/`). AI B-roll is `Setup/VideoAI.swift`. `pretty review` is `Sources/pretty/CmdReview.swift`.
- Never put API keys in files, argv, logs or test fixtures. Send a key only to its API's host (`HTTP.sameHost` for URLs an API returns); `HTTP` strips credential headers on cross-host redirects and is ephemeral (no disk cache); `HTTP.base` accepts `PRETTY_*_BASE` overrides only for https or loopback. Keychain reads go through `/usr/bin/security` (Apple-signed) so the ad-hoc CLI never triggers an approval prompt. Tests use `scripts/mock-voice-server.py` (`PRETTY_ELEVENLABS_BASE` / `PRETTY_OPENAI_BASE` / `PRETTY_GEMINI_BASE` / `PRETTY_FAL_BASE` + `test-key`); every cache key includes the API base so mock output never stands in for real output.
- Release packaging: `scripts/build.sh` then `scripts/make-dmg.sh` (dmgbuild venv in `Dev.noindex/pretty-studio/dmg-venv`). Review the onboarding with `open -n "dist/Pretty Studio.app" --args --onboarding --onboarding-step N`. The recorder's directed mode is `runScheduled` in `web-recorder/record.mjs`. Keep the planner's `lead()` estimates in sync with the recorder's `travelTime`.
- After changing recording, timing, audio or scene code, run `scripts/selftest.sh` (about 1 minute, one heavy job). It checks clicks against cues, scenes, narration placement (mock voice API), credits, loudness, and a type-only composition.
- Verify timing changes numerically by comparing `events.json` click times and beat markers against `sources/plan.json` anchors. Measure narration onsets with `silencedetect` on a voice-only render.
- Time bases: zooms, cuts, speed and content overlays use source time. Text, captions and audio use output time. `TimeMap` converts between them.
- Visual changes must be verified. Use `pretty frame <bundle> --at …` and `pretty sheet`, then look at the images. Test bundles live in a scratch dir or `/Volumes/Master Storage/Projects/pretty-studio/video/`.
- Core Image gotcha: `CIColorMatrix` works on unpremultiplied color. For opacity, scale alpha only (`CIImage.opacity`).
- ffmpeg gotcha: never fan one short input into many `adelay` branches that feed `amix`, because it can deadlock. Pre-render sample tracks (see `Media.clickTrack`), and always pass `-t` when an input loops.
